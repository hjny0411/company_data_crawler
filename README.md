
# 기업정보 자동 수집 및 데이터 품질검증 시스템

## 1. 프로젝트 개요

Python을 활용하여 웹페이지 및 기업 공시정보를
자동으로 수집하고, 데이터 품질을 검증한 후
SQLite 데이터베이스에 저장하는 미니 프로젝트입니다.

### 프로젝트 목적
- Python 기반 데이터 수집 프로세스 이해
- OpenDART API를 활용한 실제 기업정보 수집
- 데이터 결측치·중복·날짜 형식 오류 검증
- SQL 데이터베이스 구축 및 검증 이력 관리

## 2. 기술 스택

- Python
- requests
- BeautifulSoup4
- pandas
- SQLite
- OpenDART API
- Git / GitHub

## 3. 주요 구현 기능

### 3.1 웹크롤링 기초
- requests를 이용한 HTTP 요청
- BeautifulSoup으로 HTML 데이터 파싱
- CSS 선택자로 문장 및 작성자 정보 추출

### 3.2 기업정보 자동 수집
- 금융감독원 OpenDART API 활용
- 국내 기업 5개사의 기업개황 정보 수집
- 기업명, 고유번호, 대표자, 업종코드, 설립일 추출
- 반복문을 활용한 다수 기업 자동 수집

### 3.3 데이터 품질검증
- 필수 데이터 결측치 검사
- 기업 고유번호 기준 중복 검사
- 설립일 날짜 형식 검증
- 오류 개수 집계

### 3.4 데이터베이스 관리
- SQLite 기업정보 테이블 생성
- 수집 데이터 저장 및 SQL 조회
- 검증 시점별 품질검증 결과 기록
- append 방식으로 검증 이력 누적

## 4. 데이터 처리 흐름

OpenDART API
    ↓
Python requests
    ↓
pandas DataFrame
    ↓
데이터 품질검증
    ↓
SQLite companies 테이블
    ↓
SQLite validation_logs 테이블

## 5. 실행 결과

- 수집 대상: 국내 기업 5개사
- API 수집 성공: 5개사
- 필수 데이터 결측치: 0건
- 기업 고유번호 중복: 0건
- 설립일 형식 오류: 0건

※ 위 결과는 프로젝트 테스트 실행 기준입니다.

## 6. 실행 방법

1. Python 가상환경 생성 및 활성화
2. requirements.txt의 패키지 설치
3. OpenDART API 인증키 발급
4. 프로젝트 폴더에 .env 파일 생성

   DART_API_KEY=발급받은인증키

5. dart_collector.py 실행

## 7. 한계 및 개선 방향

- 현재 수집 대상이 5개 기업으로 제한됨
- 수집 실패 시 재시도 및 오류 로그 기능 미구현
- 빈 문자열 등 추가 결측 유형 검증 필요
- 기존 기업정보 테이블 교체 방식 개선 필요
- 기업정보 변경 이력 및 수집 자동화 기능 확장 예정

## 8. 프로젝트를 통해 배운 점

Python을 활용해 외부 데이터를 수집하고,
pandas로 데이터 품질을 검증한 뒤
SQLite에 저장하는 전체 과정을 경험했습니다.

특히 설립일 형식 검증 과정에서 날짜 포맷
설정 오류가 발생했고, 이를 수정하면서
데이터 자체의 오류와 검증 로직의 오류를
구분하는 중요성을 배웠습니다.
